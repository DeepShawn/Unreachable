# 够不着！Unreachable

一个**第一人称 3D 坑人小游戏**。5 关，越往后越坑；看起来很简单的每一步，都可能是陷阱。
糖果色的浮空世界、7 款可爱皮肤，支持 **iPhone / iPad（触屏）** 和 **电脑浏览器（键盘 + 鼠标）**。

<p align="center"><img src="icon.png" width="160" alt="团子猫"></p>

## 怎么运行

游戏是纯静态网页（Three.js 已放在 `vendor/` 里，不依赖 CDN），用任意静态服务器打开即可：

```bash
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

> 因为用了 ES Module，直接双击 `index.html`（`file://`）是打不开的，需要通过 http 访问。
> 部署到 GitHub Pages / Netlify / Vercel 等静态托管也可以直接用。

**iPhone / iPad：** 用 Safari 打开网址 → 分享 → “添加到主屏幕”，就能像 App 一样全屏玩。横屏、竖屏都支持。

## 操作

| | 电脑 | 手机 / 平板 |
|---|---|---|
| 移动 | `W` `A` `S` `D` | 左半屏按住拖动（虚拟摇杆） |
| 视角 | 鼠标（点击画面锁定）/ `←` `→` | 右半屏滑动 |
| 跳 | `空格` | 右下角「跳」按钮 |
| 重来 / 暂停 | `R` / `Esc` | 右上角暂停按钮 |

## 项目结构

```
index.html        UI 与样式
js/main.js        游戏主循环、角色物理、相机、状态与界面
js/levels.js      5 个关卡的陷阱脚本
js/world.js       关卡构建工具：地块、尖刺、路牌、金币、传送门、补间动画
js/env.js         天空、云海、光照、远景浮岛、粒子
js/skins.js       7 款皮肤（全部用几何体搭建）与第一人称爪爪
js/input.js       键盘 / 鼠标 / 触屏输入
js/audio.js       WebAudio 实时合成的音效与背景音乐（没有音频文件）
vendor/           Three.js r170（MIT）
```
